# Réserve d'idées

Les idées qui ne sont pas encore dans l'architecture. Une idée y entre quand elle a un prototype et un critère mesuré, ou quand Monsieur la décide. Chacun (Monsieur, les devs, Claude) ajoute ici, avec le gabarit.

## Gabarit

```
### Titre court
- Auteur, date :
- Problème résolu :
- Idée :
- Coût et risque :
- Comment la tester (prototype, critère) :
- Statut : à étudier | en prototype | intégrée (lien) | écartée (raison)
```

## Idées en attente

### Voyageurs venus de l'au-delà
- Auteur, date : Claude, 2026-10-08
- Problème résolu : entretenir l'illusion d'un monde derrière les frontières.
- Idée : de rares PNJ arrivent par une frontière, naufragés ou mourants, sans jamais pouvoir servir de guide, avec des objets inconnus et des récits (cadres d'information) ; ils repartent, meurent ou s'installent. Les récits deviennent des légendes par le système de rumeurs.
- Coût et risque : faible ; risque de briser l'illusion si trop fréquent.
- Comment la tester : simulateur sans rendu, mesurer la diffusion d'une légende sur 5 ans.
- Statut : à étudier.
