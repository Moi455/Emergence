# game : projet Godot 4 (à créer)

Hôte du jeu : éditeur, interface, audio, entrées, export Steam. Godot ≥ 4.6 (Jolt intégré). Le rendu des voxels est fait par le cœur C++ via le RenderingDevice de Godot (Vulkan), pas par les nœuds de maillage standards. Voir la phase 0 de `docs/04_feuille_de_route.md`.
